## record

スケッチを選んで動画として録画します。

録画開始前に、以下の値を上書きできます（Enter でデフォルトのまま進めることもできます）。

| 項目         | 説明                           | 備考 / デフォルト                    |
| ------------ | ------------------------------ | ------------------------------------ |
| fps          | フレームレート                 |                                      |
| total        | 録画する総フレーム数           | 計算式可（例: `60*30`）。1以上の整数 |
| start        | 開始フレーム                   | 録画開始前にこのフレーム数だけ進める |
| codec        | `vp9` または `h264`            | `vp9` → webm、それ以外 → mp4         |
| crf          | 品質（小さいほど高画質）       |                                      |
| pixelDensity | 録画時の pixelDensity          |                                      |
| timeout      | 全体のタイムアウト（分）       | `0` または負で無効。デフォルト: 60   |
| maxFail      | 連続フレーム取得失敗の許容回数 | デフォルト: 10                       |
| p5Version    | p5.js のバージョン             |                                      |
| p5Source     | p5.js の読み込み元             |                                      |

出力先は config の `outDir` です。  
`record.port` で一時的なサーバーを起動します（使用中の場合は録画を開始しません）。

録画には `record.browser.path` で指定した Chrome/Chromium バイナリを使用します（必須、ヘッドレスで起動）。

### total と start

- `total` は整数の計算式を入力可能（例: `60*30`, `1e4`, `1_000`, `0x10`）。結果は 1 以上の整数である必要があります。除算は整数除算です。
- `start` は録画開始前にそのフレーム数だけスケッチを進めます。

### timeout と maxFail

- `timeout`: 全体のタイムアウト（分）。`0` または負の値で無効（デフォルト: 60）。
- `maxFail`: 連続してフレーム取得に失敗したときの許容回数（デフォルト: 10）。

## sheet

1つまたは複数のスケッチから指定フレームをキャプチャし、コンタクトシート画像を生成します。

- PATH に `magick`（ImageMagick）が必要です。
- 録画と同じ Chrome 設定を使用します。
- 対象: `all` または `one`。
- 出力先: `sketchDir/sheet/sheet-YYYYMMDD_HHMMSS.png`。

### オプション

| 項目         | 説明                            |
| ------------ | ------------------------------- |
| frames       | キャプチャするフレーム指定      |
| pixelDensity | キャプチャ時の pixelDensity     |
| geometry     | ImageMagick の `-geometry` 形式 |
| columns      | 列数（空なら自動）              |
| label        | ラベルの有無                    |
| background   | 背景色                          |
| fill         | 塗りつぶし色                    |

### frames の記法

- `30` → フレーム 30
- `1 5` / `1,5` → 複数指定
- `0..10` → 0 以上 10 未満
- `0..10..2` → ステップ指定
- `0..100/5` → 範囲を 5 等分

### 注意

- `columns` が空の場合 → 自動で正方形に近いレイアウトになります。
- `.ignore` または `.gitignore` に書かれたスケッチは除外されます。
- 一部のキャプチャに失敗しても可能な限りシートを作成し、最後に成功枚数の概要を表示します。
